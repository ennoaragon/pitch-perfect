# Pitch Perfect

Simple cli tool using golang, to convert a digital signal input from a machine, into a fequency that can be output as a musical note.


## Required Installs to run cli tool

* Computer requires 2 third party tools, these are required
* [Port Audio](https://files.portaudio.com/docs/v19-doxydocs/index.html)
* [CGO](https://pkg.go.dev/cmd/cgohttps://pkg.go.dev/cmd/cgo)

## How to Run

* make run
* make build, to create an exe for system
* make test
